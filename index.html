Шпаргалка з Закону Гесса та Пропорцій НМТ

Алгоритми для швидких розрахунків на іспиті

🧩 Алгоритм Закону Гесса

  • • 1. Речовина-орієнтир: Знаходимо у вихідних рівняннях речовину з шуканої реакції.
  • • 2. Перевертання: Змінює знак ΔH на протилежний (+ на -, або - на +).
  • • 3. Множення коефіцієнтів: Якщо множиш рівняння на N, обов'язково помнож ΔH на N!
  • • 4. Додавання: Підсумковий ΔH = алгебраїчній сумі підготовлених ΔH.

📐 Формули Пропорцій НМТ

  • • Крок 1: Знаходимо кількість речовини: n = V / 22,4 (для газів) або n = m / M.
  • • Крок 2: Складаємо пропорцію за коефіцієнтами:
    За рівнянням (коеф. моль) → Q (кДж)
    За умовою (n моль) → X кДж
  • • Пам'ятай: ΔH та Q мають протилежні знаки (Q = -ΔH).
